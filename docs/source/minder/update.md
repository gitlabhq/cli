Update the GitLab Endpoint Agent Platform binary to the latest version. (EXPERIMENTAL)

## Synopsis

Checks for a newer GitLab Endpoint Agent Platform version and installs it. If the binary is not installed yet, `glab` downloads the latest version.

Updates do not apply when you use a custom binary set with `GLAB_MINDER_CLI_BINARY_PATH` or the `minder_cli_binary_path` configuration key.

`glab minder --update` does the same thing.

This feature is an experiment and is not ready for production use.
It might be unstable or removed at any time.
For more information, see
<https://docs.gitlab.com/policy/development_stages_support/>.

```plaintext
glab minder update [flags]
```

## Examples

```console
# Update the GitLab Endpoint Agent Platform, or download it if not installed
glab minder update

# Skip the download prompt
glab minder update --yes
```

## Options

```plaintext
  -y, --yes   Skip the download prompt when the binary is not installed.
```
