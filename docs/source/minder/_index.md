Manage AI governance and run the GitLab Endpoint Agent Platform. (EXPERIMENTAL)

## Synopsis

Manage AI governance for external agents and run the GitLab Endpoint Agent Platform (`agent-client`) through `glab`.

The `setup`, `doctor`, and `audit` subcommands manage AI governance. Every other command and flag is forwarded verbatim to the managed `agent-client` binary, except the `glab`-owned `--install`, `--update`, and `--yes` flags and the `update` command. Run `glab help minder` to see them.

`glab` downloads, verifies, and updates the managed binary for you on first use, then runs it. Running the agent-client is Linux-only for now.

Configuration options:

- `minder_cli_auto_run`: Skip the run confirmation prompt.
- `minder_cli_auto_download`: Skip the download confirmation prompt.

This feature is an experiment and is not ready for production use.
It might be unstable or removed at any time.
For more information, see
<https://docs.gitlab.com/policy/development_stages_support/>.

```plaintext
glab minder [<command>] [flags]
```

## Examples

```console
# Install the GitLab Endpoint Agent Platform into a coding agent
$ glab minder install
$ glab minder hook claude-code

# Show the binary's own help and version
$ glab minder --help
$ glab minder version

# Install or update the managed binary without running it
$ glab minder --install
$ glab minder update
```

## Environment variables

```plaintext
- `GLAB_MINDER_CLI_BINARY_PATH`: Use a local binary instead of the managed one. Skips
  download, version checks, and updates. Can also be set via the `minder_cli_binary_path`
  configuration key.
- `GLAB_MINDER_CLI_AUTO_DOWNLOAD`: Set to `true` to download the binary without a
  prompt. Required to run in a non-interactive environment such as CI.
- `GLAB_MINDER_CLI_AUTO_RUN`: Set to `true` to run the binary without a prompt.
  Required to run in a non-interactive environment such as CI.
```

## Options

```plaintext
  -h, --help      Show the agent client's help, or this text until the binary is installed.
      --install   Install the agent client binary without running it.
      --update    Check for and install updates to the binary. Same as the update command.
  -y, --yes       Skip confirmation prompts.
```
