Stop the job-level proxy started by `job-proxy start`.

## Synopsis

Stop the job-level Dependency Firewall proxy that `job-proxy start` started in this shell. You do not usually need it in a CI/CD job, because the proxy stops when the job's container stops.

```plaintext
glab dependency-firewall job-proxy stop [flags]
```

## Examples

```console
# Stop the proxy before the job ends
glab dependency-firewall job-proxy stop

```

## Environment variables

```plaintext
GLAB_DF_JOB_PROXY_STATE_DIR: directory holding the proxy's runtime state, as exported by `job-proxy start`. stop requires it to find the proxy to stop.
```
