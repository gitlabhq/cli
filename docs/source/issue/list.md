List project issues.

## Synopsis

Defaults to open items. Use `--group` to list for a group
instead of the current project.

```plaintext
glab issue list [flags]
```

## Aliases

```plaintext
ls
```

## Examples

```console
glab issue list --all
glab issue ls --all
glab issue list --assignee=@me
glab issue list --milestone release-2.0.0
glab issue list --updated-after 2026-10-01T00:00:00Z
```
